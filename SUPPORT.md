## 3. Creating an Effective Bug Report

When reporting a bug, please include:
1. **Operating System & Environment:** e.g., Windows 11 x64, Ubuntu 22.04 LTS, Python 3.12.
2. **Installation Method:** e.g., `pip install -e .`.
3. **Minimal Reproducible Example:** A short snippet of Markdown and Python code or CLI command that triggers the failure.
4. **Expected vs Actual Behavior:** What you expected to happen versus the actual output and stack trace.
