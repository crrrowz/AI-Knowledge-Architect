# Project Maintainers

This document lists the maintainers responsible for reviewing contributions, managing releases, and upholding architectural standards for **AI-Knowledge-Architect**.

---

## Active Maintainers

| Role | Focus Area | Contact / Handle |
| :--- | :--- | :--- |
| **Lead Architect** | Core Search Engine, FTS5 Indexing, Knowledge Agent | `@lead-architect` (GitHub) |
| **Security Maintainer** | SSRF Defenses, Network Fetcher, Boundary Validation | `security@ai-knowledge-architect.local` |
| **Reliability Engineer** | Pipeline Verification, Failure Recovery, Benchmarks | `@reliability-lead` (GitHub) |

---

## Responsibilities

Maintainers commit to:
- Reviewing pull requests within 5 business days.
- Upholding and validating the invariants defined in [CONTRIBUTING.md](CONTRIBUTING.md).
- Triage and remediation of security advisories within the timeframes specified in [SECURITY.md](SECURITY.md).
- Managing release builds, versioning, and documentation integrity.
